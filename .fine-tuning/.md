1. 데이터셋 만들기 (12/23 목표 : 다음의 형식대로 데이터 뽑아내기기)

{"messages": 
    [
        {"role": "system", "content": [{"type": "text", "text":"You are an expert in life science experiments. It is your role to explain and interpret the user's experimental results."}]},
        {"role": "user", "content": [{"type": "text", "text": "(실험결과 이미지를 설명하는 text데이터 및 이를 바탕으로 한 질문)..."}, {"type": "image"}]},
        {"role": "assistant", "content": [{"type": "text", "text": "저자의 이미지 해석 text 데이터를 바탕으로 한 질문에 대한 답변"}]}
        ]
    }

- '실험결과 이미지를 설명하는 text데이터'는 이미지와 그 이미지에 대한 캡션을 gpt-4o-mini에 전달하여 뽑아낸다.
- 그 데이터를 바탕으로 한 질문과 답변은 result섹션의 저자의 해석부분을 바탕으로 뽑아낸다. 그 질문과 답변의 유형은 '복잡한 추론'이다. 답변을 위해 단계별 추론이 필요한 어려운 질문을 생성하고, 답변하도록 한다. 
- 이렇게 나온 내용들을 위의 제이슨 형식에 맞춰서 넣고 제이슨 파일로 출력한다. 

2) 데이터셋 만드는 파이프라인
```

이미지 + 캡션 → 설명 텍스트 생성

저자 해석 기반 → 복잡한 추론 Q 생성

단계별 답변 생성

JSON 학습 데이터로 고정

[세부 단계]
1. (이미지 데이터 기반으로 실험결과 이미지를 설명하는 text데이터 뽑아내기-vllm런팟비용이 더 나으면 런팟으로 돌려서 뽑을 예정) t_figures_with_result_desc_v3.csv 파일에서 
fig_caption, fig_url을 GPT-4o-mini에 전달하여
실험결과 이미지 설명 텍스트를 생성하고 해당 텍스트를 
t_figures_with_result_desc_v3.csv파일의 'explan_img'라는 이름의 새로운 컬럼을 만들고 거기에 삽입하기. 
이미지url이 없는 경우엔 건너뛰기
이미지 설명(explan_img): 영어로 생성

2. 
그 explan_img 데이터와 result_desc를 바탕으로 "복잡한 추론"질문(explan_img)과 답변(result_desc의 일부)을 생성하고 json으로 데이터셋 만들기
동일한 result_section_ids인 데이터는 result_desc가 동일하므로 하나의 result_desc와 해당하는 explan_img컬럼의 데이터를 한번에 모아 질문-답변세트 만들기. 
최종 대화셋 생성 시: 질문은 한국어로 만들되, 모델이 explan_img(영어)를 참고하여 한국어로 답변하게


```
3) 데이터셋 만드는 gpt모델 

이때 가장 중요한 건:

“일관된 사고 틀을 가진 teacher”

GPT-4o-mini는:

항상 비슷한 수준

항상 같은 스타일

항상 같은 실수 유형

→ 데이터 정제 가능

GPT-4o는:

어떤 샘플은 너무 뛰어남

어떤 샘플은 과잉 해석

스타일 variance 큼

→ 데이터셋 전체 품질 불안정

⚠️ 단 하나의 예외 (중요)
👉 이 경우만 GPT-4o를 “부분적으로” 써도 됨

‘정답 검증기’ 혹은 ‘리뷰어’ 역할

예:

4o-mini가 생성한 해석

→ GPT-4o에게 질문:

Is there any inference in this explanation
that is not supported by the caption?


또는:

List any statements that may over-interpret the figure.


👉 생성은 mini, 검증은 4o

이게 최적 구조임.
```
